# 白板

主要是個人任務與專案管理儀表板，結合了時間軸卡片、艾森豪矩陣發想、甘特圖與全域日曆，並內建番茄鐘與獨立詰棋休息區。支援本機暫存與 Firebase 雲端同步。因為我時常在清單中迷失，所以我另外有製作拆解任務的心流工作區可載入白板任務。
白板網址:https://progress01.github.io/workboard/ 
工作區網址:https://progress01.github.io/workflow/

## 🛠 核心技術與架構

* **前端架構**：純 HTML, CSS (原生 CSS 變數與響應式排版), Vanilla JavaScript。無須任何編譯打包工具 (Zero Build Tools)，具備極致的輕量化特性。
* **後端與驗證**：Firebase SDK (Compat 10.8.1)
* `Firebase Auth`：支援 Google 第三方帳號登入。
* `Firestore`：手動雲端備份與還原機制 (預設存取 `Whiteboard_Data` 集合)。


* **資料儲存**：預設操作皆即時寫入瀏覽器的 `LocalStorage` 確保效能與離線可用性，並可透過工具列手動同步至雲端。

## ✨ 主要功能模組

### 1. 工作區與專案管理

* **多工作區 (Tabs)**：支援建立多個獨立分頁，卡片與節點資料依工作區進行隔離。支援一鍵將卡片「跨工作區轉移」。
* **專案標籤過濾**：系統會自動搜集各工作區內卡片與節點的 `#專案名稱`，並生成頂部專案列，點擊即可進行快速全局過濾。

### 2. 五大視覺化視圖 (Views)

* **📜 時間軸 (Timeline)**：
* 卡片式任務管理，支援設定單日或區間日期。
* 四種狀態進度燈號、四色卡片視覺分類。
* 支援無日期的「備忘錄模式」。


* **💡 發想棋盤 (Matrix)**：
* 基於 19x19 圍棋盤概念設計的靈感矩陣空間。
* 支援自由拖拉節點 (支援 Touch/Mouse Drag)。
* 內建艾森豪四象限標籤 (重要/緊急)。
* 支援單鍵將靈感節點「轉為正式排程卡片」。


* **⚡ 大事記 (Chronicle)**：
* 自動彙整具備日期的卡片，依時間先後順序進行條列式呈現。


* **📊 甘特圖 (Gantt)**：
* 自動抓取具備「區間日期」的卡片，繪製專案時程進度與天數估算。


* **📅 全域日曆 (Calendar)**：
* 跨工作區 (Cross-tabs) 彙整所有已設定日期的卡片，以日期為群組呈現全局視角。



### 3. 實用工具組

* **📖 全域筆記本 (Notebook)**：提供「自由筆記區」與「艾森豪四象限」兩種文字模板，資料獨立於各分頁之外，隨時可呼叫。
* **🍅 番茄鐘 (Pomodoro)**：頂部工具列內建 25 分鐘倒數計時器。
* **🎲 詰棋休息區 (Tsumego Widget)**：右下角獨立的浮動 19x19 圍棋視窗，可自由落子（黑/白）與清盤，供工作間隙休息、模擬推演使用。

## 📱 行動裝置優化 (Mobile First)

* 針對手機螢幕加入 `viewport-fit=cover` 與 Safe Area Inset 支援，避免被瀏海或底部系統 Home 條遮擋。
* 在小螢幕尺寸下，自動將導覽列切換為置底模式 (Bottom Navigation)。
* 按鈕設計精簡化，並針對觸控拖曳 (Touch Events) 進行邏輯適配。

## 🚀 部署與使用方式

1. **直接執行**：本系統為純前端單一 HTML 檔案，無需架設伺服器，直接透過瀏覽器開啟檔案即可使用本機所有功能。
2. **Firebase 雲端配置**：
* 若需建置屬於自己的雲端同步環境，請至 `<script>` 區塊更新 `firebaseConfig` 的設定值為您的專案金鑰。
* 需在 Firebase Console 中啟用 **Google 驗證** 與 **Firestore 資料庫** 的讀寫權限。


3. **雲端同步邏輯**：
* 操作過程預設即時自動存入本機 `LocalStorage`。
* 更換裝置或需備份時，請點擊「☁️ 存雲端」。
* 於新裝置登入後，點擊「📥 載雲端」即可下載進度並覆蓋本機資料。
